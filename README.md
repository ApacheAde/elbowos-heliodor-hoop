# Heliodor Hoop

Full-colour Python 3 neon gravity basketball arcade for ElbowOS.

Aim the bottom launcher left/right, shoot gold balls upward with gravity and bounce platforms. Dunk through moving neon hoops for points and combos.

Featured: https://x.com/ElbowOS

Drive reel: https://drive.google.com/file/d/1E4Rq_P_obexrmfSYdmOKukZuopvRiUPC/view

## Play

```bash
pip install -r requirements.txt
python3 heliodor_hoop.py --play
```

## Record a 9:16 reel

```bash
python3 heliodor_hoop.py --record
```

Needs Python 3.10+ and pygame + SDL. Dummy video driver used for headless recording.

Controls (interactive): A/D or arrows to move, SPACE to shoot.
